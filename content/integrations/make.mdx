Add watermarking or detection to a Make scenario. [Request early access](mailto:hello@etchv.com) to have the app shared with your organization.

## Connect your account

Create an [API key](/dashboard/api-keys) with `watermarks:embed`, `watermarks:detect` and/or `assets:read`, then save it in Make. Connection testing uses no credits.

## Assemble a scenario

| Step | Configuration |
| --- | --- |
| Submit Watermark / Submit Detection | Map filename and binary file data; choose Image, PDF or Video |
| Reference and retry key | For embedding, supply non-empty JSON. Map a stable source-event idempotency key |
| Get Job Status | Check `status_url` about once a minute while pending, up to 35 minutes |
| Get Watermarked File | On embed success, collect binary output using `result_url` |
| Get Detection Result | On detection success, collect JSON using `result_url` |
| Handle failure | Route `request_id` and `error_code` to your error handler |

Provide a filename with the original extension to file-result modules. **Download Asset** retrieves a retained file by ID.

Retry identical inputs with the same idempotency key. Collect job results within 24 hours. If you chose a bucket, check [storage delivery](/docs/api/webhooks#customer-storage-delivery-events) separately from watermark success.

See [shared workflow requirements](/docs/integrations#before-you-connect) and [async jobs](/docs/api/async).
