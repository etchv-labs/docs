Build a Zap that watermarks or checks files, then sends the result to your next app. [Request an early-access invite](mailto:hello@etchv.com).

## Connect your account

1. Accept the invite and add **Etchv** to your Zap.
2. Choose **Connect a new account**.
3. Add an [API key](/dashboard/api-keys) with `watermarks:embed`, `watermarks:detect` and/or `assets:read`.

The connection check uses no credits.

## Watermark a file

| Step | Configuration |
| --- | --- |
| Submit Watermark | Map file, filename, media type, JSON reference data and a stable source-event idempotency key |
| Delay | Wait about one minute |
| Get Job Status | Use `status_url`; repeat while pending, up to 35 minutes |
| Get Job Result | On success, use `result_url` and operation **Watermark** |
| Deliver | Map the returned `file` to your next action |

Save `request_id`, `asset_id` and the reference record. On failure, route `error_code` to your error handling.

For detection, select **Submit Detection** and operation **Detection** when collecting the result. Compare `watermark_id` with your records; `watermarked: false` is a completed result.

## File and retry details

- Map a Zapier **File** field with an HTTPS URL. The connector downloads it without forwarding your Etchv key to the source host.
- Retry identical inputs with the same idempotency key. Pending results are never passed downstream as files.
- Collect within 24 hours. **Download Asset** can retrieve a retained result later with `assets:read`.

See [workflow requirements](/docs/integrations#before-you-connect), [async jobs](/docs/api/async) and [asset retention](/docs/api/assets#files-and-records).
