<Endpoint method="POST" path="/watermarks/images/detect" />

Send an encoded image with the `watermarks:detect` scope. The response reports
whether Etchv found a watermark and the identifier it recovered.

## Choose sync or async

| Mode | Endpoint | What you receive |
| --- | --- | --- |
| Synchronous | `POST /watermarks/images/detect` | `200` detection JSON |
| Asynchronous | `POST /watermarks/images/detect/async` | `202` job receipt; retrieve the result later or use a webhook |

See [sync and async](/docs/api/async) for result handling. Async requests can select
a `webhook_id` to receive [signed completion events](/docs/api/webhooks).

## Request

Authenticate with `X-API-Key` and submit a multipart upload.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `file` | Image file | Yes | An encoded image, at most 20 MB and 40 megapixels |

```sh
curl --fail-with-body https://api.etchv.com/watermarks/images/detect \
  -H "X-API-Key: $ETCHV_API_KEY" \
  -F 'file=@watermarked.png'
```

## Response

A successful request returns `200` with a JSON body and an `X-Request-ID` header.

| Field | Type | Description |
| --- | --- | --- |
| `watermarked` | Boolean | Whether all frames/pages/composites recovered the same watermark |
| `confidence` | Number | Lowest per-unit decoded-bit certainty, between 0 and 1 |
| `watermark_id` | String or null | Recovered 64-character hexadecimal ID, or null when no watermark is detected |

## Interpret the result

Compare `watermark_id` with the identifier stored when you embedded the image.
Confidence does not guarantee exact recovery after edits. The ID refers to your
record; the response does not contain the original JSON, a recipient's identity,
or proof of how the image was distributed.

An image without a detected watermark is still a successful detection request
and consumes a credit. Etchv does not determine whether an arbitrary unmarked
image was generated by AI.

`units` contains an entry for each zero-indexed frame, TIFF page, or layered
composite, with `index`, `watermarked`, `confidence`, and `watermark_id`.
If only some units contain a watermark, or their identifiers differ, the top-level
`watermarked` is false and `watermark_id` is null. Inspect `units` to distinguish
partial protection from an entirely unmarked image. A successful multi-unit
detection consumes one credit for the whole file. Large animations take longer
because each frame is inspected.
