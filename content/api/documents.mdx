## Request

Send a PDF, DOCX or PPTX and a JSON reference object that is not empty. Your API key
needs the `watermarks:embed` permission. The result is the same format: a PDF stays a
PDF, and Word and PowerPoint files stay editable.

```sh
curl --fail-with-body https://api.etchv.com/watermarks/documents \
  -H "X-API-Key: $ETCHV_API_KEY" \
  -H "Idempotency-Key: investor-preview-42" \
  -F 'file=@presentation.pdf' \
  --form-string 'data={"delivery":"investor-preview-42"}' \
  -D response-headers.txt --output response-body
```

A `200` response returns the watermarked file. A `202` response returns a job receipt
instead, so check the status before you save the body as a document. Save the watermark ID
from the `X-Watermark-ID` header with your record.
[Response headers and request options](/docs/api/embed#request-options).

## Choose sync or async

| Operation | Endpoint |

## <span id="first-supported-profile" />Supported files

| Requirement | Limit |
| --- | --- |
| Document | Passive, unencrypted PDF; 1–8 unrotated pages with standard page units |
| Upload / output / detection | 20 MB / 64 MB / 64 MB |
| Rendered pixels at 144 dpi | 4 MP per page; 16.8 MP total, enough for eight A4 or US Letter pages |
| Page content | Text, vectors, scanned images or a mixture |
| Unsupported | Forms, digital signatures, active content and annotation types not listed below |

Text stays searchable and selectable. Fonts, vectors, page sizes, supported
annotations and document metadata stay the same. The watermark is stored in added
textures, which can make the file larger. Editing the layout or removing those
textures can affect recovery.

<Details title="Annotations, attachments and active content">

- **Retained:** links, text notes, popups and static `PlyBorder` annotations, including relationships and appearance streams. Borders need a normal Form appearance; actions on notes, popups and borders are unsupported.
- **JSON attachments:** retained byte-for-byte, not watermarked. Require a `.json` name, `application/json` type and valid UTF-8 JSON object/array. Maximum 64 nesting levels, 64 KB each, 256 KB total and 16 files.
- **Removed:** document/page open actions, additional actions and document-level JavaScript that run automatically.
- **Rejected:** other active content (including scripts on links), non-JSON attachments, forms and digital signatures. Scanned handwritten signatures are ordinary page content.

Annotations are retained separately and do not receive their own watermark.

</Details>

<Details title="Rendering and verification">

Etchv must detect the exact watermark on each final page. Each page must also meet
35 dB PSNR, a measure of how close the result looks to the original. Etchv checks this
with two PDF rendering engines, using a standard 144 dpi RGB rendering with
annotations hidden. Two blended textures carry the watermark; pages are not flattened.

Embed fonts in your source PDFs so they render the same everywhere. Etchv does not
add fonts to your PDF. Its verification render uses standard substitute fonts, and
other viewers may choose different ones. Printing, re-saving and edits can affect
recovery.

</Details>

## DOCX and PPTX

| Requirement | Limit |
| --- | --- |
| Files | DOCX and PPTX (Office Open XML); not macro-enabled, templates, slide shows or password-protected |
| Upload / output / detection | 20 MB / 100 MB / 95 MB in one request, 100 MB through a [large-file upload](/docs/api/uploads) |
| Watermark units | Up to 128 page or slide watermarks and images, 40 MP in total |
| Slide backgrounds | Solid colors, pictures and linear gradients; pattern fills, tiled pictures and path gradients are not supported yet |

The watermark is carried in units:

- **Pages.** Every Word header that a page shows gets a page-sized picture behind the
  text, made from the page's own color with the watermark. Sections without a
  header get one that holds only this picture.
- **Slides.** Every slide, including hidden slides, gets its background as a picture
  with the watermark. Slides with the same background share one. A gradient background
  becomes a picture of the gradient.
- **Images.** Every JPEG, PNG, GIF, BMP or TIFF image of at least 64 pixels on each side
  is watermarked in its own format. Smaller images, animations and vector graphics are
  unchanged.

Text, tables, fields, tracked changes, comments, notes, animations and layouts are
unchanged. Etchv must detect the exact watermark in every unit of the final file, and
each unit must meet 35 dB PSNR.

<Callout title="Detection reads the file">
  Detect a DOCX or PPTX by uploading the file. Its page and slide pictures and its
  images recover the watermark exactly. A screenshot, print or PDF export of a page or
  slide that is mostly text is usually not traceable, because the text covers most of
  the picture behind it. Photos in the document keep their own watermark when copied.
  Removing a header, a slide background or an image removes that unit's watermark.
</Callout>

## Billing and results

- **Embed:** one CPU credit per PDF page, so an eight-page PDF costs 8. A DOCX or PPTX costs one credit per watermark unit: each page or slide background picture and each image. If the request fails, the reserved credits are refunded.
- **Detect:** one CPU credit per file, whatever its page count. `units` reports each PDF page, or each DOCX/PPTX unit with its `part` name. For a PDF, the top-level watermark ID is present only when Etchv finds the same watermark on every page; for a DOCX or PPTX, on every unit that carries one, so images added later do not hide it.
- **Retrieve:** [job results](/docs/api/async) last 24 hours. A retry with the same [idempotency key](/docs/api/async#retry-safely) returns the saved file without another charge.
