Use the HTTP status and the JSON `detail` field to handle a failure. Save the `X-Request-ID` header when you report a problem.

## Status codes

| Status | What to do |
| --- | --- |
| `401` · Authentication | Check the API key |
| `402` · Billing | Check the plan, credit balance and pending reservations |
| `403` · Access | Check [scopes](/docs/authentication), membership, [formats](/docs/billing) and [GPU eligibility](/docs/api/gpu) |
| `404` · Not found | Check the ID in the request (asset, job, webhook or destination) and the Organization |
| `409` · Conflict | Check idempotency inputs or reload a stale asset version |
| `410` · Unavailable result | Check the asset library; the file may be expired or deleted |
| `413` · Too large | Reduce file size, dimensions or frame count |
| `415` · Unsupported format | Convert to a supported format |
| `422` · Invalid input or verification failure | Check encoding and JSON; try a different source if verification failed |
| `429` · Limit reached | Wait for `Retry-After` seconds, then retry |
| `503` · Service unavailable | Check [service status](https://status.etchv.com) and retry appropriately |

## Rate limits

Limits apply to all your Organization’s keys and dashboard use combined. See [allowances by plan](/docs/billing#api-rate-limits).

| Limit | What counts |
| --- | --- |
| Requests per minute | Every authenticated request, including polling, downloads and refused requests; resets each minute |
| Concurrent operations | Queued or running embedding and async detection jobs, plus durable video detection |

Synchronous image and PDF detection count only toward requests per minute. Replaying an existing job does not use another concurrent slot.

A `429` response reserves no credits. Its `detail` includes `code` (`rate_limited` or `concurrency_limited`) and `limit`. Concurrency errors also include `upgrade_url`.

| Header | Meaning |
| --- | --- |
| `Retry-After` | Seconds to wait |
| `X-RateLimit-Limit` | Requests allowed this minute |
| `X-RateLimit-Remaining` | Requests left this minute |
| `X-RateLimit-Reset` | Minute reset time, as Unix seconds |

When you poll (check a job’s status again and again), wait at least the job’s `Retry-After`: 6 seconds on Trial and Launch, 2 on other plans. [Webhooks](/docs/api/webhooks) let you skip polling. SDKs retry `429` for embedding, video detection and polling until the client timeout. Other calls return the error.

## Image limits

| Limit | Maximum |
| --- | --- |
| Embedding upload | 50 MB via API; 20 MB via dashboard |
| Delivered file | 192 MB; lossless output can be larger than the upload |
| Detection upload | 95 MB via API or dashboard |
| Frames or pages | 32, including an APNG poster image |
| Total pixels | 40 megapixels across frames or pages |
| GIF frame | 1 megapixel |
| PSD/PSB canvas | 4 megapixels |
| PSD/PSB layers | 64 layers and 16 megapixels total, including two watermark layers |

Send the encoded file bytes and a JSON `data` object that is not empty. URLs and base64 strings are not file uploads. High-bit-depth and CMYK images are not supported. HEIC, HEIF and AVIF return `415`. Convert them to JPEG, PNG or WebP first.

## Credits and retries

Embedding reserves credits when Etchv accepts the request. It charges them when the checked output is saved, and releases them if the job fails for good. Downloads and replays add no charge. During an outage, reserved credits stay pending until a worker finishes or closes out the job.

| Situation | Action |
| --- | --- |
| Client timeout | Resume with the request ID, or resend the same inputs and [idempotency key](/docs/api/async#retry-safely); the accepted job continues |
| Final `status: "failed"` | Inspect `error_code`; the same key returns the same failure |
| Sync image/PDF detection error | Handle in your code; SDKs do not retry these calls automatically |
| Upload to your own storage fails | Inspect [delivery errors](/docs/storage); the checked output is still valid and retries add no charge |

See [retry rules](/docs/api/async#retry-safely) and [credit costs](/docs/billing#what-uses-credits).
