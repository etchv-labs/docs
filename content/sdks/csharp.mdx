## Install

```sh
# From your project folder: clone next to it, not inside it
git clone --branch v1.0.0 https://github.com/etchv-labs/csharp-sdk.git ../etchv-csharp-sdk
dotnet add reference ../etchv-csharp-sdk/src/Etchv/Etchv.csproj
```

Install from the tagged GitHub source; there is no official NuGet package.

## Embed a file

Set `ETCHV_API_KEY` on your server. This example needs `watermarks:embed` and `watermarks:detect`, an active plan and available credits.

```csharp
using Etchv;

using var client = new EtchvClient(Environment.GetEnvironmentVariable("ETCHV_API_KEY")!);
var key = await client.GetApiKeyInfoAsync(); // OrganizationId, KeyId, Scopes; no credits used
var result = await client.EmbedImageAsync(await File.ReadAllBytesAsync("photo.jpg"),
    new Dictionary<string, object?> { ["asset"] = "photo-123" },
    new RequestOptions(Filename: "photo.jpg"));
await File.WriteAllBytesAsync(result.Filename, result.Bytes);
var detection = await client.DetectImageAsync(result.Bytes, new RequestOptions(Filename: result.Filename));
Console.WriteLine($"{detection.Watermarked} {detection.WatermarkId} {detection.Confidence:P0}");
```

`GetApiKeyInfoAsync` checks credentials for free. Write output bytes without re-encoding.

## Images, documents and video

| Media | Embed / detect methods |
| --- | --- |
| [Images](/docs/api/embed) | `EmbedImageAsync` / `DetectImageAsync` |
| [PDFs](/docs/api/documents) | `EmbedDocumentAsync` / `DetectDocumentAsync` |
| [Videos](/docs/api/videos) | `EmbedVideoAsync` / `DetectVideoAsync` |

Native output is in `result.Bytes` for every media type. Embedding also returns `WatermarkId`, `RequestId`, `ContentType`, `Filename`, `AssetId`, `SourceAssetId` and `StorageDeliveryId`.

Detection returns the ID, confidence and per-frame/page results—not the original JSON. [Result fields](/docs/api/detect#response) · [Credits](/docs/billing#what-uses-credits).

<Details title="Client configuration">

`new EtchvClient(key, baseUrl, timeout, httpClient)` sets the timeout (default 120 seconds) and optional `HttpClient`. Custom HTTP handlers must disable redirects.

Every operation takes a `CancellationToken`; cancellation raises `OperationCanceledException`. Use `RequestOptions(Filename: ..., IdempotencyKey: ...)` for media requests. Later recipes assume an open client.

</Details>

## Retries and recovery

Embedding and video detection retry and poll automatically; image/PDF detection does not. Save an idempotency key before uploading to recover across restarts.

| Situation | Action |
| --- | --- |
| Client timeout | The accepted job continues; resume or resend identical inputs with the same key |
| Resume a job | `GetEmbedResultAsync(requestId)` / `GetDetectionResultAsync(requestId)` |
| Changed inputs | Use a new key; reusing one returns `409` |
| Collect a saved result | Within 24 hours; see [retention](/docs/api/assets#files-and-records) |

<Details title="Error types and handling">

`EtchvException` exposes `StatusCode`, `RequestId`, `IdempotencyKey`, `Detail`, `ErrorCode` and `ErrorStatus`. Status `0` indicates a network failure or client deadline.

```csharp
try
{
    var output = await client.GetEmbedResultAsync(requestId);
}
catch (EtchvException e) when (e.StatusCode == 410)
{
    // The saved result expired or its asset was deleted (e.ErrorStatus).
}
catch (EtchvException e)
{
    logger.LogError("Etchv {Status} request {RequestId}", e.StatusCode, e.RequestId);
}
```

See [HTTP errors](/docs/api/errors) and [retry behavior](/docs/api/async#retry-safely). Save the request ID when reporting failures.

</Details>

## Asset library

Scopes: `assets:read` for downloads, `assets:write` for edits, `assets:delete` plus owner/admin for deletion. No credits used.

<Details title="List, edit and download assets">

```csharp
var page = await client.ListAssetsAsync(new AssetListOptions(Kind: "watermarked"));
foreach (var item in page.Items) {
    var asset = await client.GetAssetAsync(item.Id);
    var updated = await client.UpdateAssetAsync(asset.Id, asset.Version,
        new Dictionary<string, object?> { ["metadata"] = new { campaign = "spring" } });
    if (updated.FileAvailable) {
        byte[] bytes = await client.DownloadAssetAsync(updated.Id);
    }
}
// Use NextCursor with the same filters to continue listing.
```

Edits replace metadata and require the current version; reconcile `409` conflicts. `DeleteAssetAsync` / `DeleteAssetsAsync` delete one asset or 1–50 atomically. [Asset fields, filters and retention](/docs/api/assets).

</Details>

## Async jobs and webhooks

Submit for a receipt without waiting: `SubmitEmbedAsync` / `SubmitDetectionAsync`; media: `images`, `documents`, `videos`. These return a `JobReceipt`; the `Async` suffix on regular methods refers to C# async I/O, not server submission mode.

`GetJobAsync(requestId)` for embedding; `GetJobAsync(requestId, detect: true)` for detection.

<Details title="Submit and collect an async job">

Load the media bytes before submitting.

```csharp
var job = await client.SubmitEmbedAsync("documents", pdfBytes,
    new Dictionary<string, object?> { ["delivery"] = "delivery_001" },
    new RequestOptions("document.pdf", "delivery_001"), webhookId);
var status = await client.GetJobAsync(job.RequestId);
if (status.Status == "succeeded")
{
    var output = await client.GetEmbedResultAsync(job.RequestId);
}
```

The webhook is optional (Java/Rust: pass `null` / `None`). Save the receipt. [Job handling](/docs/api/async).

</Details>

<Details title="Manage endpoints and verify webhooks">

Methods: `CreateWebhookAsync`, `ListWebhooksAsync`, `UpdateWebhookAsync`, `DeleteWebhookAsync`, `ListWebhookDeliveriesAsync`, `RedeliverWebhookAsync`. Use `webhooks:read` to inspect or `webhooks:write` plus owner/admin to manage. Save the one-time signing secret.

```csharp
using var buffer = new MemoryStream();
await request.Body.CopyToAsync(buffer);
if (!WebhookSignature.Verify(buffer.ToArray(), request.Headers["X-Etchv-Timestamp"],
        request.Headers["X-Etchv-Signature"], signingSecret))
    return Results.Unauthorized();
// Parse JSON, check id == X-Etchv-Event-ID, deduplicate, enqueue work, then return 2xx.
```

`WebhookSignature.Verify` checks the signature and timestamp. Your handler must also compare the body ID with `X-Etchv-Event-ID`. Use raw bytes and a 300-second tolerance. Deduplicate, enqueue, then return `2xx`. [Verification rules](/docs/api/webhooks#verify-every-delivery).

</Details>

## GPU processing

Pass `new RequestOptions(Accelerator: Accelerator.Gpu)` on Business or Enterprise. GPU uses 3× credits; CPU fallback uses normal credits. `result.Accelerator` reports the accelerator used. See
[GPU processing](/docs/api/gpu).

## Choose where results are stored

[Connect your bucket](/docs/storage), then pass its destination ID and optional object key. Omit both for Etchv storage.

<Details title="Deliver to your bucket">

```csharp
var job = await client.SubmitEmbedAsync("documents", pdfBytes,
    new Dictionary<string, object?> { ["recipient"] = "customer-123" },
    new RequestOptions(Filename: "report.pdf", IdempotencyKey: "report-export-001",
        StorageDestinationId: destinationId, StorageKey: "reports/watermarked.pdf"));
// After the watermark job reports succeeded:
var delivery = await client.GetStorageDeliveryAsync((await client.GetJobAsync(job.RequestId)).StorageDeliveryId!);
if (delivery.Status == "failed") await client.RetryStorageDeliveryAsync(delivery.Id);
```

After job success, inspect delivery with `storage:read` (earlier reads return `404`). Once `stored`, use `DownloadStorageDeliveryAsync` to download.

With `storage:write` and owner/admin access, `RetryStorageDeliveryAsync` retries failed/cancelled delivery for free. Manage with: `CreateStorageDestinationAsync`, `VerifyStorageDestinationAsync`, `UpdateStorageDestinationAsync`, `DeleteStorageDestinationAsync`, `CreateStorageDeliveryAsync`. See [delivery recovery](/docs/storage#retry-retention-and-deletion).

</Details>
