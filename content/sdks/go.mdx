Go 1.25+. Import the package as `etchv`; reuse one concurrency-safe client. MIT licensed.

## Install

```sh
go get github.com/etchv-labs/go-sdk@v1.0.0
```

## Embed a file

Set `ETCHV_API_KEY` on your server. This example needs `watermarks:embed`, an active plan and available credits.

```go
package main

import (
    "context"
    "log"
    "os"

    etchv "github.com/etchv-labs/go-sdk"
)

func main() {
    ctx := context.Background()
    client, err := etchv.New(os.Getenv("ETCHV_API_KEY"))
    if err != nil { log.Fatal(err) }
    key, err := client.CheckAPIKey(ctx) // no credits used
    if err != nil { log.Fatal(err) }
    log.Printf("organization %s, scopes %v", key.OrganizationID, key.Scopes)

    file, err := os.ReadFile("photo.jpg")
    if err != nil { log.Fatal(err) }
    result, err := client.EmbedImage(ctx, file,
        map[string]any{"asset": "photo-123"}, etchv.Options{Filename: "photo.jpg"})
    if err != nil { log.Fatal(err) }
    if err := os.WriteFile(result.Filename, result.Bytes, 0o600); err != nil { log.Fatal(err) }
}
```

`CheckAPIKey` checks credentials for free. Write output bytes without re-encoding.

## Images, documents and video

| Media | Embed / detect methods |
| --- | --- |
| [Images](/docs/api/embed) | `EmbedImage` / `DetectImage` |
| [PDFs](/docs/api/documents) | `EmbedDocument` / `DetectDocument` |
| [Videos](/docs/api/videos) | `EmbedVideo` / `DetectVideo` |

Native output is in `result.Bytes` for every media type. Embedding also returns `WatermarkID`, `RequestID`, `ContentType`, `Filename`, `AssetID`, `SourceAssetID` and `StorageDeliveryID`.

Detection returns the ID, confidence and per-frame/page results—not the original JSON. [Result fields](/docs/api/detect#response) · [Credits](/docs/billing#what-uses-credits).

<Details title="Client configuration">

`etchv.New(key, etchv.WithBaseURL(url), etchv.WithTimeout(d), etchv.WithHTTPClient(c))`

The default timeout is 120 seconds. Every call takes a context for cancellation. Set `Options.Filename` and `Options.IdempotencyKey` per media request. Later recipes assume an open client and `ctx`.

</Details>

## Retries and recovery

Embedding and video detection retry and poll automatically; image/PDF detection does not. Save an idempotency key before uploading to recover across restarts.

| Situation | Action |
| --- | --- |
| Client timeout | The accepted job continues; resume or resend identical inputs with the same key |
| Resume a job | `GetEmbedResult(ctx, requestID)` / `GetDetectionResult(ctx, requestID)` |
| Changed inputs | Use a new key; reusing one returns `409` |
| Collect a saved result | Within 24 hours; see [retention](/docs/api/assets#files-and-records) |

<Details title="Error types and handling">

Failures are `*etchv.Error` with `StatusCode`, `Detail`, `RequestID`, `IdempotencyKey`, and job `JobStatus` / `ErrorCode` when available. Status `0` means network failure, cancellation or client deadline; `errors.Is(err, context.DeadlineExceeded)` works.

```go
var apiErr *etchv.Error
if errors.As(err, &apiErr) {
    log.Printf("HTTP %d, request %s: %s", apiErr.StatusCode, apiErr.RequestID, apiErr.Detail)
}
```

See [HTTP errors](/docs/api/errors) and [retry behavior](/docs/api/async#retry-safely). Save the request ID when reporting failures.

</Details>

## Asset library

Scopes: `assets:read` for downloads, `assets:write` for edits, `assets:delete` plus owner/admin for deletion. No credits used.

<Details title="List, edit and download assets">

```go
page, err := client.ListAssets(ctx, etchv.AssetListOptions{Kind: "watermarked", Limit: 25})
if err != nil { return err }
for _, item := range page.Items {
    asset, err := client.GetAsset(ctx, item.ID)
    if err != nil { return err }
    _, err = client.UpdateAsset(ctx, asset.ID, etchv.AssetUpdate{
        Version: asset.Version, Metadata: map[string]any{"campaign": "spring"},
    })
    if err != nil { return err }
}
// Continue with AssetListOptions{Cursor: *page.NextCursor} and the same filters until nil.
file, err := client.DownloadAsset(ctx, assetID) // file.Bytes, file.ContentType, file.Filename
```

Edits replace metadata and require the current version; reconcile `409` conflicts. `DeleteAsset` / `DeleteAssets` delete one asset or 1–50 atomically. [Asset fields, filters and retention](/docs/api/assets).

</Details>

## Async jobs and webhooks

Submit for a receipt without waiting: `SubmitEmbed` / `SubmitDetection`; media: `etchv.MediaImages`, `etchv.MediaDocuments`, `etchv.MediaVideos`.

`GetEmbedJob` for embedding; `GetDetectionJob` for detection.

<Details title="Submit and collect an async job">

Load the media bytes before submitting.

```go
job, err := client.SubmitEmbed(ctx, etchv.MediaDocuments, pdfBytes,
    map[string]any{"delivery": "delivery_001"},
    etchv.Options{Filename: "document.pdf", IdempotencyKey: "delivery_001", WebhookID: webhookID})
if err != nil { return err }
status, err := client.GetEmbedJob(ctx, job.RequestID)
if err != nil { return err }
if status.Status == "succeeded" {
    result, err := client.GetEmbedResult(ctx, job.RequestID)
    // ...
}
```

The webhook is optional (Java/Rust: pass `null` / `None`). Save the receipt. [Job handling](/docs/api/async).

</Details>

<Details title="Manage endpoints and verify webhooks">

Methods: `CreateWebhook`, `ListWebhooks`, `UpdateWebhook`, `DeleteWebhook`, `ListWebhookDeliveries`, `RedeliverWebhook`. Use `webhooks:read` to inspect or `webhooks:write` plus owner/admin to manage. Save the one-time signing secret.

```go
body, err := io.ReadAll(io.LimitReader(r.Body, 1<<20))
if err != nil { http.Error(w, "bad request", 400); return }
event, err := etchv.VerifyWebhook(body, r.Header, os.Getenv("ETCHV_WEBHOOK_SECRET"))
if err != nil { http.Error(w, "invalid signature", 400); return }
// Deduplicate on event.ID, enqueue work, then return 2xx.
```

`VerifyWebhook` verifies the signature, timestamp and matching event ID. Use raw bytes and a 300-second tolerance. Deduplicate, enqueue, then return `2xx`. [Verification rules](/docs/api/webhooks#verify-every-delivery).

</Details>

## GPU processing

Pass `etchv.Options{Accelerator: etchv.AcceleratorGPU}` on Business or Enterprise. GPU uses 3× credits; CPU fallback uses normal credits. `result.Accelerator` reports the accelerator used. See
[GPU processing](/docs/api/gpu).

## Choose where results are stored

[Connect your bucket](/docs/storage), then pass its destination ID and optional object key. Omit both for Etchv storage.

<Details title="Deliver to your bucket">

```go
job, err := client.SubmitEmbed(ctx, etchv.MediaDocuments, pdfBytes,
    map[string]any{"recipient": "customer-123"}, etchv.Options{
        Filename: "report.pdf", IdempotencyKey: "report-export-001",
        StorageDestinationID: destinationID, StorageKey: "reports/watermarked.pdf",
    })
if err != nil { return err }
// After the watermark job reports succeeded:
delivery, err := client.GetStorageDelivery(ctx, *job.StorageDeliveryID)
```

After job success, inspect delivery with `storage:read` (earlier reads return `404`). Once `stored`, use `DownloadStorageDelivery` to download.

With `storage:write` and owner/admin access, `RetryStorageDelivery` retries failed/cancelled delivery for free. Manage with: `CreateStorageDestination`, `VerifyStorageDestination`, `UpdateStorageDestination`, `DeleteStorageDestination`, `CreateStorageDelivery`. See [delivery recovery](/docs/storage#retry-retention-and-deletion).

</Details>
