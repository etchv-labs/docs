Java 21+. Gson is the only runtime dependency. Reuse one thread-safe client and close it when finished. MIT licensed.

## Install

Maven:

```xml
<dependency>
  <groupId>com.etchv</groupId>
  <artifactId>etchv-sdk</artifactId>
  <version>1.0.0</version>
</dependency>
```

Gradle (Kotlin DSL):

```kotlin
implementation("com.etchv:etchv-sdk:1.0.0")
```

## Embed a file

Set `ETCHV_API_KEY` on your server. This example needs `watermarks:embed` and `watermarks:detect`, an active plan and available credits.

```java
import com.etchv.EtchvClient;
import java.nio.file.*;
import java.util.Map;

class Example {
    public static void main(String[] args) throws Exception {
        try (var client = new EtchvClient(System.getenv("ETCHV_API_KEY"))) {
            System.out.println(client.getApiKeyInfo().scopes()); // no credits used
            var result = client.embedImage(Files.readAllBytes(Path.of("photo.jpg")),
                Map.of("asset", "photo-123"), new EtchvClient.Options("photo.jpg", null));
            Files.write(Path.of(result.filename()), result.bytes());
            var detection = client.detectImage(result.bytes(), null);
            System.out.println(detection.watermarked() + " " + detection.confidence());
        }
    }
}
```

`getApiKeyInfo` checks credentials for free. Write output bytes without re-encoding.

## Images, documents and video

| Media | Embed / detect methods |
| --- | --- |
| [Images](/docs/api/embed) | `embedImage` / `detectImage` |
| [PDFs](/docs/api/documents) | `embedDocument` / `detectDocument` |
| [Videos](/docs/api/videos) | `embedVideo` / `detectVideo` |

Native output is in `result.bytes()` for every media type. Embedding also returns `watermarkId()`, `requestId()`, `contentType()`, `filename()`, `assetId()`, `sourceAssetId()` and `storageDeliveryId()`.

Detection returns the ID, confidence and per-frame/page results—not the original JSON. [Result fields](/docs/api/detect#response) · [Credits](/docs/billing#what-uses-credits).

<Details title="Client configuration">

`EtchvClient(key, baseUrl, Duration)` sets the timeout (default 120 seconds). Calls block and propagate `InterruptedException` on thread interruption. Use `new EtchvClient.Options(filename, idempotencyKey)` for media requests. Run later recipes inside the open client’s scope.

</Details>

## Retries and recovery

Embedding and video detection retry and poll automatically; image/PDF detection does not. Save an idempotency key before uploading to recover across restarts.

| Situation | Action |
| --- | --- |
| Client timeout | The accepted job continues; resume or resend identical inputs with the same key |
| Resume a job | `getEmbedResult(requestId)` / `getDetectionResult(requestId)` |
| Changed inputs | Use a new key; reusing one returns `409` |
| Collect a saved result | Within 24 hours; see [retention](/docs/api/assets#files-and-records) |

<Details title="Error types and handling">

Unchecked `EtchvClient.EtchvException` exposes `statusCode()`, `requestId()`, `idempotencyKey()` and `detail()`. Status `0` means no response was received; `isGone()` identifies HTTP 410.

```java
try {
    var result = client.getEmbedResult(requestId);
} catch (EtchvClient.EtchvException e) {
    if (e.isGone()) {
        // Saved result expired or its asset was deleted; retrying does not charge again.
    }
    log.warn("Etchv failed: status={} requestId={}", e.statusCode(), e.requestId());
}
```

See [HTTP errors](/docs/api/errors) and [retry behavior](/docs/api/async#retry-safely). Save the request ID when reporting failures.

</Details>

## Asset library

Scopes: `assets:read` for downloads, `assets:write` for edits, `assets:delete` plus owner/admin for deletion. No credits used.

<Details title="List, edit and download assets">

```java
var page = client.listAssets(Map.of("kind", "watermarked", "limit", "25"));
for (var item : page.items()) {
    var asset = client.getAsset(item.id());
    var updated = client.updateAsset(asset.id(), asset.version(),
        Map.of("metadata", Map.of("campaign", "spring")));
    if (updated.fileAvailable()) {
        byte[] bytes = client.downloadAsset(updated.id());
    }
}
// Use nextCursor() with the same filters to continue listing.
```

Edits replace metadata and require the current version; reconcile `409` conflicts. `deleteAsset` / `deleteAssets` delete one asset or 1–50 atomically. [Asset fields, filters and retention](/docs/api/assets).

</Details>

## Async jobs and webhooks

Submit for a receipt without waiting: `submitEmbed` / `submitDetection`; media: `images`, `documents`, `videos`. Submission returns a JSON receipt.

`getJob(requestId, false)` for embedding; `getJob(requestId, true)` for detection.

<Details title="Submit and collect an async job">

Load the media bytes before submitting.

```java
var job = client.submitEmbed("documents", pdfBytes, Map.of("delivery", "delivery_001"),
    new EtchvClient.Options("document.pdf", "delivery_001"), webhookId);
String requestId = job.get("request_id").getAsString();
var status = client.getJob(requestId, false);   // queued, running, retrying, succeeded, failed
var result = client.getEmbedResult(requestId);  // waits while the job is pending
```

The webhook is optional (Java/Rust: pass `null` / `None`). Save the receipt. [Job handling](/docs/api/async).

</Details>

<Details title="Manage endpoints and verify webhooks">

Methods: `createWebhook`, `listWebhooks`, `updateWebhook`, `deleteWebhook`, `listWebhookDeliveries`, `redeliverWebhook`. Use `webhooks:read` to inspect or `webhooks:write` plus owner/admin to manage. Save the one-time signing secret.

```java
boolean valid = EtchvClient.verifyWebhookSignature(rawBody,
    request.getHeader("X-Etchv-Timestamp"), request.getHeader("X-Etchv-Signature"), signingSecret);
if (!valid) throw new SecurityException("Invalid webhook signature");
// Then check the body id equals X-Etchv-Event-ID, deduplicate, enqueue work, and return 2xx.
```

`verifyWebhookSignature` checks the signature and timestamp. Reject an invalid signature, then compare the body ID with `X-Etchv-Event-ID`. Use raw bytes and a 300-second tolerance. Deduplicate, enqueue, then return `2xx`. [Verification rules](/docs/api/webhooks#verify-every-delivery).

</Details>

## GPU processing

Pass `options.withAccelerator(EtchvClient.Accelerator.GPU)` on Business or Enterprise. GPU uses 3× credits; CPU fallback uses normal credits. `result.accelerator()` reports the accelerator used. See
[GPU processing](/docs/api/gpu).

## Choose where results are stored

[Connect your bucket](/docs/storage), then pass its destination ID and optional object key. Omit both for Etchv storage.

<Details title="Deliver to your bucket">

```java
var job = client.submitEmbed("documents", pdfBytes,
    Map.of("recipient", "customer-123"),
    new EtchvClient.Options("report.pdf", "report-export-001", destinationId,
        "reports/watermarked.pdf"), null);
// After the watermark job reports succeeded:
var delivery = client.getStorageDelivery(job.get("storage_delivery_id").getAsString());
```

After job success, inspect delivery with `storage:read` (earlier reads return `404`). Once `stored`, use `downloadStorageDelivery` to download.

With `storage:write` and owner/admin access, `retryStorageDelivery` retries failed/cancelled delivery for free. Manage with: `createStorageDestination`, `verifyStorageDestination`, `updateStorageDestination`, `deleteStorageDestination`, `createStorageDelivery`. See [delivery recovery](/docs/storage#retry-retention-and-deletion).

</Details>
