You need an image and an [Etchv account](/signup) with credits.
The free trial includes 200 credits for seven days.

## Set your API key

Create a [key](/dashboard/api-keys) with `watermarks:embed` and `watermarks:detect`.
Keep it on your server. For a local terminal:

```sh
export ETCHV_API_KEY="YOUR_API_KEY"
```

## Embed a watermark synchronously

Replace `photo.jpg` with your image. Use a unique reference for this delivery and
a new idempotency key for each new operation.

```sh
curl --fail-with-body https://api.etchv.com/watermarks/images \
  -H "X-API-Key: $ETCHV_API_KEY" \
  -H "Idempotency-Key: campaign-01-partner-42" \
  -F 'file=@photo.jpg' \
  --form-string 'data={"delivery":"partner-42-preview"}' \
  -D response-headers.txt --output response-body
```

Check the status in `response-headers.txt`:

| Status | Next step |
| --- | --- |
| `200` | Save the bytes using the `Content-Disposition` filename, such as `photo-watermarked.jpg` |
| `202` | The body is a JSON job receipt. [Follow its `result_url`](/docs/api/async#retrieve-a-pending-result-either-mode) to collect the image |
| Error | Read the [error response](/docs/api/errors); the body is not an image |

Save `X-Watermark-ID` with your delivery record. Keep `X-Request-ID` for recovery
or support. Write the returned bytes directly; re-encoding can affect recovery.

## Detect the watermark

```sh
curl --fail-with-body https://api.etchv.com/watermarks/images/detect \
  -H "X-API-Key: $ETCHV_API_KEY" \
  -F 'file=@photo-watermarked.jpg'
```

Compare `watermark_id` with your saved ID. The response also includes `watermarked`
and `confidence`; a missing mark returns a null ID. [Interpret detection results](/docs/api/detect#interpret-the-result).

## Find your files again

Use `X-Asset-ID` and `X-Source-Asset-ID` to find the output and original in the
[asset library](/docs/api/assets). Etchv keeps files for 30 days on the trial and up to a year on a paid plan; records remain until deleted.

## Prefer an asynchronous request?

Append `/async` to the embedding endpoint. Keep the same fields; collect the
result later or request a webhook. [Sync and async guide](/docs/api/async).
